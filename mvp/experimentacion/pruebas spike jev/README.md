# Pruebas del spike Jev

Las pruebas de **Jev** dentro del MVP: someter a juicio lo que devuelve el ORQ —la respuesta, el
material que leyó y el documento radicado— y leer el grado por bandas.

Siguen `mvp/politicas_experimentacion.md`: cada prueba se define **antes** de correr —la pregunta,
lo que se deja fijo, lo que se cambia, la vara y lo que se observa— y deja su resultado acá, con
`rN`.
